How it works

Upload → convert → download

One-line version
upload → nginx (TLS + size check) → FastAPI (validate + save to tmpfs)
       → magick CLI (decode images → render PDF pages) → FastAPI reads result
       → temp files deleted → PDF streamed back → browser downloads it

Everything between steps 4–6 happens inside a single HTTP request/response cycle — nothing persists before or after.

Privacy

Your files are never stored.

pdfyier converts your images to a PDF and sends it straight back to your browser. Nothing about the process is designed to keep a copy.

What happens to your files:

Uploaded images are held only in memory (RAM-backed temporary storage, never written to disk) for the few seconds it takes to build your PDF. The moment your download starts, that memory is cleared — on the server and inside the container that runs the conversion.

What we log:

Standard web server logs record your IP address, the time of the request, and the response status — the same information any website's server logs by default. We do not log filenames, file contents, or anything from inside your upload.

Third parties:

None. Conversion happens entirely on our own server. Your files are never sent anywhere else.

Accounts and cookies:

There are none. pdfyier doesn't require sign-in and doesn't set tracking cookies.

Help

Quick answers.

How do I add images?

Click the dropzone to choose files, or drag images directly onto it from your computer.

How do I change the page order?

Drag any thumbnail to a new position before converting. The number in the top-left corner of each image shows its page order.

Can I rename the download?

Yes — use the "File name" field above the Convert button. It always saves as a .pdf.

What file types are supported?

JPG, PNG, WEBP, BMP, TIFF, and GIF, up to 20MB each.

Why did my upload fail?

Usually one of: a file over the size limit, an unsupported format, or too many conversions in a short time. Wait a moment and try again.

Is there a limit on file count?

Up to 50 images per conversion, 150MB combined.
